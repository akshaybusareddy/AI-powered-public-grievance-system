## 🚀 How to Run

### Quick Start (3 Steps)

1. **Install Dependencies**
```bash
cd server && npm install
cd ../client && npm install
```

2. **Configure Environment**
```bash
# Copy .env.example to .env in both folders
# Add your MongoDB URI and OpenAI API key
```

3. **Start Application**
```bash
# Terminal 1 - Backend
cd server && npm run dev

# Terminal 2 - Frontend
cd client && npm start
```

### Optional: Seed Database
```bash
cd server && npm run seed
```

## 📊 Database Schema

### Users Collection
```javascript
{
  _id: ObjectId,
  name: String,
  email: String (unique),
  password: String (hashed),
  role: "citizen" | "official",
  department: "Roads" | "Electricity" | "Drainage" | "Sanitation",
  createdAt: Date
}
```

### Complaints Collection
```javascript
{
  _id: ObjectId,
  citizenId: ObjectId (ref: User),
  complaintText: String,
  imageUrl: String,
  location: String,
  department: String,
  priority: "High" | "Medium" | "Low",
  priorityReason: String,
  status: "Pending" | "In Progress" | "Resolved",
  resolutionRemarks: String,
  updatedBy: ObjectId (ref: User),
  createdAt: Date,
  updatedAt: Date
}
```

## 🎯 API Endpoints

### Authentication
- `POST /api/auth/register` - Register citizen
- `POST /api/auth/login` - Login user
- `GET /api/auth/me` - Get profile

### Complaints
- `POST /api/complaints` - Create complaint
- `GET /api/complaints/my` - Get my complaints
- `GET /api/complaints/department` - Get dept complaints
- `GET /api/complaints/:id` - Get complaint
- `PATCH /api/complaints/:id/status` - Update status
- `GET /api/complaints/stats` - Get statistics
